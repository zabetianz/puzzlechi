# 🧩 پازلچی

یه بازی پازل کشویی (Sliding Puzzle) با رابط کاربری فارسی و طراحی رنگی و شاد.

## ویژگی‌ها
- شروع از صفحه‌ی ۳×۳ و افزایش تدریجی سختی تا ۵×۵
- محدودیت زمانی برای هر مرحله
- قابل بازی با کلیک، لمس گوشی، یا کیبورد (کلیدهای جهت‌دار)
- ذخیره‌ی بهترین امتیاز در مرورگر

## نحوه‌ی اجرا
فایل `puzzlechi.html` رو باز کن یا از طریق GitHub Pages به صورت آنلاین بازی کن.
